# meeting-karigor-mcp

**Using Meeting Karigor from your AI assistant.** For people whose organization uses Meeting Karigor, and for anyone whose AI assistant (Claude, ChatGPT, Gemini, Codex) is connected to Karigor's MCP server: it teaches the assistant how Meeting Karigor really works today, from planning a meeting to its minutes and memory, so the assistant calls only the tools in its own tool list, names the exact app button for every step that has no tool, never changes access settings, never records, sends or approves anything by itself, and answers from meeting memory only with a citation. **What you need first:** a Karigor account with Meeting Karigor in the app. For tool access, an assistant that can add a remote MCP server with sign-in; ask hello@karigor.ai for the server address, sign in with the same Karigor account you use in the app, and ask your organization's owner to turn MCP and the tools you need on in the app at Settings, MCP access (a karigor's own tools also need a Karigor super admin to give you access). Without a connection, the skill still works as a step-by-step guide to the app. **In Claude**, add the folder as a skill (Claude Code: copy it to `~/.claude/skills/meeting-karigor-mcp/`; Claude apps: upload the folder as a ZIP under Skills in settings), then ask about a meeting, for example "how do I record an online meeting?". **In ChatGPT**, follow `chatgpt-instructions.md` to make a Custom GPT or Project, or paste its box into a new chat. **In Gemini**, create a Gem and paste the same box into its instructions. **In Codex** and other tools that read the Agent Skills format, copy the folder to `~/.agents/skills/` or to `.agents/skills/` in your project. `examples.md` is its test suite: fifteen cases, each with "Must" and "Must not" lines.
