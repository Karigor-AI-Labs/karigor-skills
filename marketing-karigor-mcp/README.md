# marketing-karigor-mcp

**Using Marketing Karigor through MCP.** For people who use Karigor's Marketing Karigor and want their AI assistant to work it for them over MCP (Claude, ChatGPT, Gemini, Codex or another tool that connects to MCP servers), and for Karigor's own assistants: it teaches the assistant the order of the steps (read, ask for a plan, wait for the owner to approve it in the app, hand the kept lines to Content Karigor, read the weekly report), what each step costs in credits, which steps only a person can do in the Karigor app, how to read a refusal, and what a plan does not read, and it never approves a plan, never posts, and never changes MCP access.

**What you need first.** A Karigor account with Content Karigor, and a role in a Marketing Karigor (owner or editor). MCP turned on for you: the owner of your organization turns MCP and each tool on in the Karigor app at Settings, MCP access, and a Karigor super admin turns Marketing Karigor on over MCP for your organization and for you. Then your assistant connected to Karigor's MCP server, signed in with the same Karigor account you use in the app. Ask Karigor for the server address. We have connected with Claude Code; we have not tested other assistants yet.

**How to start.** **In Claude Code**, connect with `claude mcp add --transport http karigor <the address from Karigor>`, sign in when asked, and copy this folder to `~/.claude/skills/marketing-karigor-mcp/`. **In Claude apps**, upload the folder as a ZIP under Skills in settings. **In ChatGPT**, follow `chatgpt-instructions.md`. **In Codex** and other tools that read the Agent Skills format, copy the folder to `~/.agents/skills/` or to `.agents/skills/` in your project. Then ask: "Plan next week with Marketing Karigor." `examples.md` is its test suite: sixteen cases, each with "Must" and "Must not" lines.
