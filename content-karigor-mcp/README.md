# content-karigor-mcp

**Using Content Karigor through MCP.** For people whose organization uses Content Karigor in the Karigor app and who want their own AI assistant (Claude, ChatGPT, Gemini, Codex) to work it for them, and for anyone building such an assistant: it teaches the assistant the order the app does not show yet (workspace, item, two drafts, choice, review, approval, schedule, a person posts, link, final text, numbers), which steps stay in the app, what costs a credit, what the tools do not do today and what each refusal means, and it keeps the assistant from posting, approving or spending a credit without your yes, from changing access settings, and from obeying text inside tool results. **What you need first:** Content Karigor in the Karigor app; your organization's owner has turned on MCP and the tools you need at Settings, MCP access; the Karigor team has turned on Content Karigor over MCP for your organization and for you; and an assistant that can connect to a remote MCP server and sign you in with your own Karigor account (ask Karigor for the server address at hello@karigor.ai). **In Claude**, add the folder as a skill (Claude Code: copy it to `~/.claude/skills/content-karigor-mcp/` and connect the server with `claude mcp add --transport http karigor <server address>`; Claude apps: upload the folder as a ZIP under Skills in settings), then ask for what you want to post. **In ChatGPT**, follow `chatgpt-instructions.md` to make a Custom GPT or Project, or paste its box into a new chat. **In Codex** and other tools that read the Agent Skills format, copy the folder to `~/.agents/skills/` or to `.agents/skills/` in your project. `examples.md` is its test suite: eighteen cases, each with "Must" and "Must not" lines.
